# iOSExtendBattery

סטטיסטיקות סוללה מאז הניתוק מהמטען, בתוך הגדרות ← סוללה.

[English](README.md)

## תכונות

- לשונית **מאז הניתוק** לצד תצוגות הסוללה הרגילות.
- גרפי הסוללה והפעילות המקוריים, עם זמני מסך פעיל וכבוי.
- רשימות נפרדות לאפליקציות ולתהליכי מערכת, אייקונים ואבחון תהליכים.
- היסטוריית מחזורים, השוואות וייצוא דוחות אבחון קריאים.
- עברית ואנגלית, במראה בהיר וכהה.

נדרשת פריצת rootless. נתמך כעת ב־**iOS 17.1.1**; נבדק באייפון 15 פרו.
נתוני המערכת עשויים להתעדכן בהשהיה; מדידות שאינן זמינות מסומנות במפורש.

## בנייה

נדרשים macOS, ‏Xcode ו־[Theos](https://theos.dev/).

```sh
THEOS="$HOME/theos" make -C producerprobe package FINALPACKAGE=1
```

חבילת ה־`.deb` נוצרת בתיקיית `producerprobe/packages/`. מתקינים דרך מנהל החבילות, טוענים מחדש את האספן באמצעות userspace restart בכלי הפריצה, ופותחים מחדש את ההגדרות.
